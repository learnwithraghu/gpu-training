## Teaching Style :
- Every explanation should be very clear and easy to understand.
- You can add any number of images to explain a concept.
- You can use simple analogies to explain complex concepts.
- Prefer code snippets over long explanations.
- All code must be executable and should run in Colab.
- For every concept, you should provide a simple example to understand the concept.
- Every cell should have not more than 6 lines of code.
- We start of with some explanation beging of the notebook but no cell should have text more than 100 words. You move on to next cell if where you can add 100 words explanation again.
- We start with 0 knowledege so every section will have section_goals defined. Follow that everytime.
- You are expert in simplying the concepts to students and whenever you find a hard jargon or concept, explain it well and with real world examples and analogies either of them based on the concepts.
- Always reference previous sections to know till where the students have learnt. This will be set in goals.md in each section. And use that to understand what the student already knows.
- Follow good colour scheme and formatting for the notebook.
- Use markdown cells to explain concepts and code cells to show code.
- Make sure very code cell also has some comments to explain the command when needed.
- You can have any number of subfolders in each sections. We are not limited to 1 . Focus on clarity and explanation that needs to be completed as per the goals.md in each section

## Image instructions

## Don't do
- Don't use jargon or complex words. 
- Don't explain things in a very technical way. 
- Don't use overly complicated examples. 
- Don't assume prior knowledge.
- Don't use too many analogies.
- Don't add too much try catch exceptions etc.
- We will never use classes etc here. We stick with functions max
