# Section 05 - GPUs for DevOps and MLOps

## Teaching Outcome

Learners can monitor GPU utilization, explain latency/throughput behavior, and produce an ops runbook.

## Session Plan (75 minutes)

1. GPU observability fundamentals
2. Utilization and memory diagnostics
3. Inference latency simulation
4. Incident-style troubleshooting drill

## Teaching Notes

- Frame this as operations readiness, not only model training.
- Require concrete thresholds for alerts and saturation.
- End with a runbook checklist learners can reuse.
