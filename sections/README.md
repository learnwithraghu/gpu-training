# Sections

**`sections/` is the canonical source.** All learner and instructor content lives here.

The notebooks in this directory are built for a complete solo tutor experience (see `LEARNER_TUTOR_DESIGN.md`). They no longer rely on a live human to fill in the "why", the model answers, or the "what if I got confused" support.

Each section contains:

- `LEARNING_GUIDE.md` — practical instructor session plan + teaching notes (still excellent for live delivery)
- `notebooks/` — Colab notebooks that follow the full coached learning loop: prediction prompts, tiny experiments, rich interpretation, misconception repair, revealed model answers, role relevance for DevOps/DS/DE, lesson recaps, and clear next-step previews.
