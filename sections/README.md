# Sections

This curriculum is organized as teachable sections instead of phase-based docs.

Each section contains:

- `LEARNING_GUIDE.md` - a practical instructor guide
- `notebooks/` - runnable Colab notebooks with explanation-first flow

Order:

1. `00-colab-and-gpu-setup`
2. `01-gpu-fundamentals`
3. `02-gpu-programming-without-fear`
4. `03-gpus-for-data-science`
5. `04-gpus-for-data-engineering`
6. `05-gpus-for-devops-mlops`
7. `06-optimization-and-cost-engineering`
8. `07-capstone-projects-by-role`
