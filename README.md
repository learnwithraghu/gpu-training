# GPU Engineering From Scratch

This repository is now organized as instructor-first `sections/` content.

## Core Structure

- `sections/` - clean teaching guides and notebooks for each section
- `idea.md` - long-form curriculum direction and rationale
- `ROADMAP.md` - rollout checkpoints for the section-first curriculum

## Teaching Path

Follow sections in order:

1. Colab and GPU setup
2. GPU fundamentals
3. GPU programming without fear
4. GPUs for data science
5. GPUs for data engineering
6. GPUs for DevOps and MLOps
7. Optimization and cost engineering
8. Capstone projects by role

Each section includes:

- a `LEARNING_GUIDE.md` you can teach from directly
- at least one notebook with explanation-first cells before code cells
