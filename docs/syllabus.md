# Syllabus

## Phase 00 - Colab and GPU Setup

Goal: make every learner productive in Google Colab with GPU runtime checks and baseline benchmarking habits.

## Phase 01 - GPU Fundamentals

Goal: build intuition for CPU vs GPU, memory hierarchy, throughput/latency, and matrix multiplication performance.

## Phase 02 - GPU Programming Without Fear

Goal: teach practical acceleration patterns (vectorization, device placement, avoiding transfer overhead).

## Phase 03 - GPUs for Data Science

Goal: improve model training speed and memory efficiency with practical PyTorch techniques.

## Phase 04 - GPUs for Data Engineering

Goal: apply GPU acceleration to ETL and analytics workflows.

## Phase 05 - GPUs for DevOps and MLOps

Goal: understand GPU scheduling, observability, and serving tradeoffs in production-like scenarios.

## Phase 06 - Optimization and Cost Engineering

Goal: optimize for both speed and cost with precision, batching, and quantization techniques.

## Phase 07 - Capstone Projects by Role

Goal: deliver role-specific capstones for DevOps, Data Science, and Data Engineering tracks.
