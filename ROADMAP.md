# Roadmap

## Phase Rollout Strategy

### Wave 1 (MVP Foundations)

- Complete `00-colab-and-gpu-setup`.
- Complete `01-gpu-fundamentals`.
- Launch public GitHub Pages site with copy-enabled code blocks.

### Wave 2 (Acceleration Core)

- Ship `02-gpu-programming-without-fear`.
- Ship `03-gpus-for-data-science`.
- Add mixed precision and batch tuning benchmark labs.

### Wave 3 (Infrastructure and Data)

- Ship `04-gpus-for-data-engineering`.
- Ship `05-gpus-for-devops-mlops`.
- Add production simulation artifacts (runbooks, profiling templates).

### Wave 4 (Optimization and Capstone)

- Ship `06-optimization-and-cost-engineering`.
- Ship `07-capstone-projects-by-role`.
- Publish role-specific capstone rubrics and completion criteria.

## Quality Standards

- Each Build/Project lesson has a runnable Colab notebook.
- Each lesson has `docs/en.md` and at least one output artifact.
- Catalog generation and lesson validation pass in CI.

## Success Metrics

- Learners can run all MVP labs in Colab without local setup.
- Lesson pages provide copy buttons for every code block.
- GitHub Pages deployment is automated and stable.
