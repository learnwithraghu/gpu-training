# Glossary

## CUDA Core
A processing unit on NVIDIA GPUs optimized for parallel arithmetic operations.

## Tensor Core
Specialized GPU unit optimized for matrix operations used in deep learning.

## VRAM
GPU memory where tensors and model parameters are stored during execution.

## Throughput
How much work is completed per unit time.

## Latency
Time taken for one request or operation to complete.

## Mixed Precision
Using lower precision data types (like FP16) to speed up compute and reduce memory usage.

## Batch Size
Number of samples processed together in one forward/backward pass.
